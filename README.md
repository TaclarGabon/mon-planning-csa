## Version
V4 validée — migration GitHub effectuée.

## Fonctions
- Direction
- Professeurs
- Mes classes
- Élèves
- Parents
- Emplois du temps Aujourd’hui / Semaine
- Présence école : À confirmer / Présent / Absent

- En cours / Libre selon l’emploi du temps

- Réinitialisation de la démo
